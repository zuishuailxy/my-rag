## 关键实现决策

- **append_turn 必须显式赋 `updated_at = func.now()`**：标题不变且无字段变更时 SQLAlchemy 不发 UPDATE，updated_at 会停在上轮；TS 靠 `new Date()` 强制 save() 触发更新。仅靠 ORM onupdate 不够（onupdate 只在真的有 UPDATE 语句时生效）。
- 删除顺序与 TS 保真：先删消息再删会话（DDL 有 CASCADE 但不依赖库级）。
- QuerySessionRequest 的 page/pageSize 补了上下界（page≥1，pageSize 1~100）——TS 源未贴、按项目分页惯例收紧，已注释文档化。
- FastAPI 语法坑：**无默认值的 Annotated Depends 参数必须放在带默认值的 Query 参数之前**，否则 SyntaxError。
