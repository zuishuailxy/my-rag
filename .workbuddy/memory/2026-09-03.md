`document.controller.ts` + `document.module.ts`，要求对齐文档端点的逐接口权限码。

### init.sql 补齐 kh_role_permission
- 原文只有 8 行（USER 缺 document:edit(13)/delete(14)，REVIEWER 缺 search 菜单(3)）。
- 补齐为 11 行完整矩阵（用户给的 11 行块）。权限码 ID 映射：
  document:list=11 / create=12 / edit=13 / delete=14 / review=15；search=3(menu)。
- 新增 `scripts/seed_role_permission_matrix.py`（幂等 INSERT ... ON CONFLICT DO NOTHING），
  运行后运行库 8→11 行。已有库同步沿用此脚本。

### document.py 16 个端点加 `require_permission`
- 逐接口装饰器（OR 语义，与 TS @RequirePermission 同款）：create/upload→document:create、
  GET列表/详情→document:list、publish/archive/save-draft/submit/update→document:edit、
  delete→document:delete、reviews/current+history→document:list+document:review、
  4 个审核接口额外 document:review（与 @roles(REVIEWER,ADMIN) 并存）。
- ADMIN 经 ADMIN_OPERATION_PERMISSIONS 自动拥有全部，admin 冒烟不受影响。
