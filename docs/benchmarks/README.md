# 压测原始数据

## 2026-10-29 重测（commit e751a24）

**为什么要重测**：2026-10-09 那批只把 p50 记进了结论（脚本只 print 不落盘），
p95、max、TTFT、RPS 全部丢失。原始 per-request 耗时不存在了，**只能重跑，不能反推**。

**这次改了什么**（`scripts/load_test.py`）：

| 改动 | 原因 |
|---|---|
| 新增 `--out` 落盘 | 存**每请求的原始耗时数组** + 环境元信息；聚合值不存，事后随便重算 |
| 新增 `--rounds` | 样本数 = 并发 × 轮数。n≤20 时 p95 会退化成 max（最近秩取到最后一个），必须多轮 |
| **修正 TTFT 口径** | 旧代码取第一个 `data:` 帧 —— 那是 SSE 的 `start` 帧，在业务逻辑之前就发了。真正的 TTFT 取首个 `text-delta` / `reasoning-delta` |
| 修正 stream 请求体 | 旧代码对 `/chat/stream` 也发 `content`，端点要的是 `messages`，**一直 422** —— 也就是说历史上的「TTFT」从未真正测到过 |
| 修 `error_sample` 的 KeyError | 非 200 响应没有 `error` 键，`errors[0]["error"]` 直接抛 |

复现命令：

```bash
cd backend && PYTHONPATH=. RABBITMQ_ENABLED=false \
    .venv/bin/python scripts/load_test.py \
    --levels 5,10,20,40,100 --rounds 3 --endpoint stream --out docs/benchmarks/xxx.json
```

## 结果三：TTFT 分段拆解（60 样本，并发 10/20）

日志格式：`本轮耗时：sessionId=…, ttft_ms=…, total_ms=…, stages=session:38,history:13,…`

| 阶段 | 做什么 | p50 | p95 | max | 占 TTFT |
| --- | --- | --- | --- | --- | --- |
| `memory` | Mem0 长期记忆检索 | **1847ms** | 3520ms | 4215ms | **40%** |
| `classify` | 意图路由（TypeSafe → 失败回退 LLM） | **1653ms** | 3799ms | 7309ms | **36%** |
| `summary` | 滚动摘要读取 | 174ms | 306ms | 309ms | 4% |
| `stream` | 模型流式输出（mock，仅首个 delta 前） | 68ms | 483ms | 1166ms | 1% |
| `session` | 会话读/建 | 38ms | 227ms | 235ms | 1% |
| `persist` | 落库（TTFT 之后） | 27ms | 2282ms | 2485ms | — |
| `history` | 热窗口历史加载 | 13ms | 21ms | 32ms | 0% |
| `prepare` | 建 agent + 拼 messages | 6ms | 61ms | 616ms | 0% |
| **TTFT** | 请求进来到首个 token | **4626ms** | 7029ms | 8693ms | — |
| **total** | 到响应结束 | 4992ms | 7113ms | 8743ms | — |

**这张表是本次最重要的产出**：TTFT 4.6 秒里，**76% 花在两个外部依赖上**
（Mem0 检索 40% + 意图路由 36%），自己的代码（会话/历史/摘要/建 agent）只占约 5%。

## 已知问题（本次暴露，未修）

1. **连接在等外部服务时被占着**。每个流式请求持有连接 4.6 秒，其中 3.5 秒在等
   Mem0 / TypeSafe。这正是 README 第 6 节那个根因（「连接跨外部调用持有」）的
   翻版——当时修的是权限查询，现在多出来的是长期记忆与意图路由。
2. **TypeSafe 区域受限**（HTTP 451），每次请求都先白等一次失败往返才回退 LLM，
   这段直接计入 `classify`。加熔断可以删掉它。
3. **并发 40 的 32 秒是 `pool_timeout`，不是处理时间**。任何引用这个数字的地方
   都要写明，否则会被读成「系统处理一个请求要 32 秒」。
